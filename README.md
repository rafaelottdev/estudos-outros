# Estudos Outros

Repositório para anotações, exemplos e estudos relacionados ao desenvolvimento web.

## Conteúdos

* **ESLint** — Linting e análise de código
* **Biome** — Linting e formatação de código
* **Prettier** — Formatação de código
* **Vitest** — Testes unitários
* **MSW** — Mock de APIs e requisições HTTP
* **Testing Library** — Testes de componentes e interfaces
* **Playwright** — Testes End-to-End (E2E)
* **Postman** — Testes de APIs
* **CI/CD** — Integração e entrega contínuas
